# Taller 2 - Churn FinAlpes

Taller 2 de Ciencia de Datos Aplicada (MINE-4101), 2026-20.

La idea es predecir qué clientes del banco se van a ir (churn), entender qué está mirando el modelo y calcular cuánta plata se ganaría usándolo en campañas de retención.

## Archivos

- `Taller2.ipynb`: el notebook con todo el desarrollo
- `churn.csv`: los datos (10.045 clientes, la columna a predecir es `churn`)
- `Taller2.pdf`: el enunciado

## Cómo correrlo

Se necesita Python con pandas, numpy, matplotlib, seaborn y scikit-learn. Abrir `Taller2.ipynb` en Jupyter y correr todas las celdas en orden. El csv tiene que estar en la misma carpeta del notebook.
